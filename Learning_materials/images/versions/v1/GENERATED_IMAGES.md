# L11 generated images for the learning materials

Record of every AI-generated illustration planned for `Learning_materials/skripta.qmd`. The plan follows open choice 5 of the Stage 2 record (`Workflow/records/2026-10-21-stage-2-learning-materials.md`), decided by Ondřej Mottl on 2026-10-21: the dataset has no licensed photographs, so the illustrations below are generated by a separate agent from these prompts. Quantitative figures (the 8 + 8 tank design, data plots) are drawn in R from the data and are never replaced by a generated image.

Store each finished file under this folder with the file name given below. Until a file exists, its reserved slot in `skripta.qmd` shows nothing and no disclosure. The presentation (Stage 4) may later reuse the same cast for its own series, recorded separately in `Presentation/Materials/GENERATED_IMAGES.md`.

## Series identity

- Recurring cast: a plains leopard frog field ecologist (*Lithobates blairi*: brown-green frog with dark rounded spots and pale dorsolateral ridges) with a small field notebook and a measuring ruler, and a dragonfly assistant (a blue-green hawker dragonfly). Both appear in every image with a consistent appearance; the dragonfly matters again in the dragonfly-larvae design of Part F.
- Settings: small shallow pools and ponds in a Central European landscape (meadow, field margin, woodland edge); outdoor round cattle-tank mesocosms in a field station meadow.
- Style: warm storybook natural-history watercolour/gouache; gentle academic humour; natural anatomy of frogs, tadpoles, froglets and dragonflies.
- Palette: the course `_brand` palette only as small accents; no large purple or orange areas, so the semantic colours of the data figures (grey data, purple model, orange focus) stay free.
- Global constraints: no text, letters, numbers, axes, tick marks, charts, labels, logos or watermarks. No image may show or imply a numerical result (for example which frogs are larger) or a specific number of tanks.
- Format: landscape 3:2, PNG, genuine transparent RGBA background with irregular vignette edges (user style correction, 2026-10-21), at least 1500 px wide; legible when shown at text width in HTML and in the A4 PDF.
- Disclosure: every image is shown with the caption suffix „Ilustrace vytvořená pomocí AI.“

## Generation and style correction - 2026-10-21

All four assets were generated through OpenAI built-in `image_gen`, with no CLI/API fallback. The tool does not expose the underlying model identifier. Exact submitted prompts, reference paths, selected output identifiers, image metadata and SHA-256 values are recorded in `GENERATED_IMAGE_PROMPTS_20261021.json`.

The user rejected the first full-bleed landscape because its style did not match previous lectures. That first S1 image was not installed; the remaining first-series batch was stopped and none of its outputs was selected. The replacement series uses the actual L10 `ostrovy_pruzkum.png` and L09 `stromy_mereni.png` as style references: rich natural-history watercolour/gouache, expressive animal researchers, compact habitat vignettes and organic transparent edges. Selected S1 was also supplied to S2-S4 to maintain the recurring frog and dragonfly. This recorded style correction supersedes the original opaque-background plan; scene roles, filenames, Czech alt text and captions above remain applicable. The historical scene prompts above are retained; the JSON contains the exact revised prompts.
